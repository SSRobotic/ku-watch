# บันทึกภาพและวิดีโอทดสอบจริง

|---|---|---|---|---|---|
| รอเพิ่มภาพ/วิดีโอจริง | | | | | |

ภาพสรุป JSON ในโฟลเดอร์หลักมีเวลาเก็บและไฟล์ผลประกอบแล้ว ตารางนี้สำหรับภาพจอจริง ภาพบอร์ด และวิดีโอเท่านั้น
