# จอใหญ่ KU HUB 1.0.5

ใช้กับตัวเล็ก2.0.5 จอใหญ่ส่งเวลาจากPCF85063กลับเมื่อเวลาตัวเล็กยังไม่พร้อม โดยต้องมีUTC markerและRTCไม่หยุด/oscillatorไม่เสีย เวลาที่รับจากHUBจะไม่วนกลับมาเขียนRTCเดิม GPS/NTPยังปรับได้ การดับทั้งสองบอร์ดยังต้องตรวจแบตสำรองRTCจริง

ใช้กับ Waveshare ESP32-S3-Touch-LCD-2.1 ที่ COM8 ตัวเล็กยังเป็นนาฬิกาปุ่มเดียวตามเดิม ตัวเล็กใช้แบตได้ระหว่างจอใหญ่ต่อ USB

เปิดทั้งสองบอร์ด จอใหญ่ค้นหาตัวเล็กและจับคู่ ESP-NOW อัตโนมัติ เมื่อขึ้น `ESP-NOW LIVE` จะแสดงข้อมูลจริงที่ตัวเล็กส่งมา การจับคู่ไม่ต้องใช้อินเทอร์เน็ต แต่ถ้าตัวเล็กต่อ Wi-Fi จอใหญ่ต้องค้นหาช่องเดียวกับ Wi-Fi ของตัวเล็ก

ปุ่มล่างจอใหญ่: `PREV` หน้าก่อนหน้า, `HOME` หน้านาฬิกา, `NEXT` หน้าถัดไป ขณะออนไลน์จอใหญ่ส่งคำสั่งให้ตัวเล็กเปลี่ยนหน้าด้วย เมื่อไม่มีการเชื่อมต่อยังดูเมนูจอใหญ่ได้ แต่ค่าที่ต้องมาจากตัวเล็กจะเป็น `--` และปุ่มเปลี่ยนข้อมูลปิดไว้

| หน้า | ปุ่มเฉพาะหน้า |
|---|---|
| ENVIRONMENT | `TEMP -` / `TEMP +` ปรับเกณฑ์เตือนอุณหภูมิของตัวเล็กครั้งละ 1°C |
| MOTION | `CALIBRATE` เริ่มสอบเทียบเข็มทิศของตัวเล็ก ต้องหมุนตัวเล็กตามขั้นตอนเดิม |
| NETWORK | `PHONE SETUP` เปิดหน้าตั้งค่ามือถือบนตัวเล็ก |
| MAP | `AREA` สลับบางเขน/มิตรอินทรีย์ อำนาจเจริญ; `ZOOM` เปลี่ยนระดับซูม |
| WALK | `START WALK` เริ่มบันทึกบนตัวเล็กเมื่อมีเวลาที่เชื่อถือได้; `STOP + SAVE` หยุดและบันทึก |
| AIR QUALITY | `IAQ -` / `IAQ +` ปรับเกณฑ์เตือน IAQ ครั้งละ 10 |
| ROBOT | `FEED` / `PLAY` ส่งคำสั่งดูแล KU-BOT ที่ตัวเล็ก |

PREV/HOME/NEXT เปลี่ยนเมนูจอใหญ่ตั้งแต่แตะ รุ่น 1.0.3 อ่านทัชแยกทุก 4 ms และเก็บจังหวะแตะ/ปล่อยไว้ในคิวระหว่างวาดภาพ ปุ่มมีพื้นที่กดเพิ่มและรับ completed tap ผ่าน interrupt เพื่อรองรับการแตะสั้น ถ้ามีคำสั่งอื่นรอ ACK อยู่จะเก็บหน้าล่าสุดไว้ส่งตามทันทีเมื่อส่งได้ ไม่มีการเขียน NVS ทุกครั้งที่เปลี่ยนเมนู

ปุ่มเปลี่ยนข้อมูล เช่น WALK/FEED ให้แตะแล้วปล่อยหนึ่งครั้งต่อคำสั่ง หน้าจอขึ้น `SENDING TO WATCH` ระหว่างรอ และ `WATCH CONFIRMED` เมื่อได้รับ ACK ถ้า `BUSY - TRY AGAIN` หรือ `NO ACK - TRY AGAIN` ให้รอแล้วลองใหม่ ตรวจสถานะที่ตัวเล็กด้วยสำหรับคำสั่งที่เปลี่ยนข้อมูล การกดทัชค้างไม่ใช้เป็นการส่งซ้ำ

เวลาบนจอใหญ่รับจากตัวเล็กและซิงค์ PCF85063 เป็น UTC จากนั้นแสดงเวลาไทย UTC+7 ถ้าการเชื่อมต่อขาดแต่ RTC ยังมีเวลาถูกต้อง จะขึ้น `HUB RTC TIME` การเดินเวลาตอนถอดไฟทั้งหมดต้องมีแบตสำรอง RTC และยังไม่ได้ทดสอบตัดไฟจริง RTC ของจอใหญ่ในรุ่นนี้ยังไม่ส่งเวลากลับไปตั้งให้ตัวเล็ก

จุด GPS ขึ้นเมื่อข้อมูล GPS ของตัวเล็กผ่านเกณฑ์ แผนที่มีสองพื้นที่เดิมและจำพื้นที่ล่าสุดในจอใหญ่ เส้นเดินที่จอใหญ่เห็นเป็นช่วงที่ได้รับข้อมูลสดตั้งแต่เปิดจอใหญ่ ส่วนกิจกรรมเต็มบันทึกและส่งออกจากตัวเล็กตามเดิม

ตรวจบนบอร์ดจริงแล้ว: ภาพจอใหญ่ขึ้นตามคำยืนยันผู้ใช้, ตัวเล็กใช้แบต, telemetry สดที่ช่อง 11, RTC ซิงค์ได้ และคำสั่ง MAP → ENVIRONMENT → HOME ได้ ACK พร้อมหน้าตอบกลับตรงคำสั่งครบสามหน้า อายุแบต ระยะวิทยุ การดับไฟ RTC และความแม่นยำการวัดยังเป็นการทดสอบแยก

รุ่นแก้ทัช 1.0.2: ผู้ใช้ยืนยันว่าแตะ NEXT ครั้งเดียวเปลี่ยนหน้าได้ บันทึกจริงพบ TOUCH `(322,431)` → NEXT → PAGE 1 → ACK OK และ `page=1`, `watchpage=1` ตรงกัน ไม่มี timeout หรือ touch I²C error หลักฐานอยู่ที่ `../output/large_touch_v102_user.json` และ `../output/large_touch_confirmed.json`

ผู้ใช้รายงานอาการแตะซ้ำอีกหลังทดสอบครั้งเดียวใน 1.0.2 จึงยังไม่ถือว่าทัชผ่านระยะยาว รุ่น 1.0.3 แก้การเก็บเหตุการณ์ทัชและทำข้อความตรวจสอบ USB แบบไม่รอคอมเปิดรับ ผู้ใช้ยืนยันหลังแก้ 1.0.3 ว่าแตะแล้วเปลี่ยนทุกครั้งได้เลย

ตรวจบนบอร์ด 1.0.3 หลังหยุดอ่าน USB 25 วินาทีแล้ว: ทัชอ่านทุก 4–5 ms, คิวไม่ล้น, ไม่มี I²C error/radio timeout และ HOME ได้ ACK พร้อมหน้าตรงกับตัวเล็ก หลักฐาน `../output/large_touch_v103_no_reader.json`

ผลทัชต่อเนื่อง 1.0.3: ผู้ใช้ยืนยัน «เปลี่ยนทุกครั้งได้เลย» บันทึก `../output/large_touch_v103_user_followup.json` พบ NEXT 7 ครั้งและ HOME 1 ครั้ง แต่ละ contact ส่งคำสั่งครั้งเดียว ทุกคำสั่งได้ ACK OK สุดท้าย HOME ทั้งจอใหญ่/ตัวเล็ก, dropped=0, toucherr=0, timeout=0 ยังไม่ได้สรุปอายุแบต/ระยะวิทยุระยะยาวจากการทดสอบนี้

รุ่น1.0.4เพิ่มแถบเตือนแบตต่ำจากตัวเล็ก (≤20%และยกเลิกเมื่อ≥22%), แสดง HUB/WATCH versionจริงที่หน้า NETWORK และข้อความ ESTIMATE - NOT MEDICAL ที่หน้า HEART RATE คิวอ่านทัชอิสระและข้อความ USB แบบไม่รอยังคงอยู่ ผู้ใช้ยืนยันว่าเห็น HUB1.0.4/WATCH2.0.2 และแตะได้ปกติ ดู `../ความต้องการ_สถานะล่าสุด.md` สำหรับเกณฑ์ตรวจรับและข้อที่ยังค้าง

# อัปเดต 1.0.5 / ตัวเล็ก 2.0.5

จอใหญ่ส่งเวลาจาก RTC ที่เชื่อถือได้กลับตัวเล็กโดยอัตโนมัติ เมื่อเชื่อม ESP-NOW และตัวเล็กยังไม่มีเวลา GPS/NTP รับช่วงซิงค์ต่อได้ ภาพ/ทัช/ปุ่มตัวเล็กยังใช้งานแบบเดิม ต้องมีไฟเลี้ยง RTC ต่อเนื่องหรือแบตสำรองที่ตรวจจริงหากต้องการจำเวลาระหว่างปิดไฟทั้งสองบอร์ด
