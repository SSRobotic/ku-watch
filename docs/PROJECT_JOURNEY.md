# Project journey

The photographs document my development process: enclosure design, component layout, wiring, mechanical corrections, local display work and backend integration. Work-stage ordering is inferred from visible content; early screen clocks and social-media filenames are not used as a verified timeline. Historical readings are not final acceptance results.
